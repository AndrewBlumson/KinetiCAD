Generated by [collect-notices.mjs](collect-notices.mjs) from the frozen installed packages.
The copied upstream files are byte-for-byte originals. The [manifest](manifest.json) records
package metadata, each notice hash and the lockfile hash. The scope deliberately includes
UI dependencies that may be unused or removed by tree shaking; it is not a bundle analysis.
Package metadata is not a substitute for a missing licence/copyright notice.

The [supplemental manifest](supplemental-manifest.json) records separately retrieved,
pinned upstream texts. Eighteen installed package versions omit notice files; these
have upstream project references below. The exact source-version correspondence for
react-remove-scroll-bar 2.3.8 remains unverified and is expressly marked.

See [THIRD-PARTY-NOTICES](../THIRD-PARTY-NOTICES.md) for attribution, the separately loaded
OCCT kernel and fonts, and remaining distribution checks.

Run from the repository root after `pnpm install --frozen-lockfile`:

```sh
node licenses/collect-notices.mjs
node licenses/collect-notices.mjs --check
```

Generation updates the expected files without deleting old notices. Review removed
dependencies explicitly if the lockfile changes. `--check` compares installed metadata
and copied bytes, and verifies the recorded supplemental hashes; it does not certify
licence compliance or fetch/revalidate upstream files.
